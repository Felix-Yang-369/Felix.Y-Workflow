# 具象知识讲解

让学习者先在脑中看见系统的构造与变化，再理解原理，最后计算。默认使用用户的语言；零件、物理量与符号在图、文字和公式中保持同名。

## 先选可见的对象

确认要解释的机器、结构或过程，以及用户想知道的是“长什么样”“怎么运行”“为什么如此”还是“怎么算”。从一件熟悉的实物或一个具体工况入手。复杂系统先划定边界，说明哪些部件暂时省略。

## 讲解路径：先看见，再理解，再计算

1. **视觉化结构**：先给清晰的实物示意、结构图、截面图或简图；标明观察方向、系统边界、输入与输出。图像不可用时用有标签的文字示意，避免装饰性图片。
2. **部件与连接**：逐个标注关键部件、连接方式和相对位置，说明每个部件的作用。不要将示意图误称为精确工程图。
3. **动态流程**：用连续的步骤或多帧图展示运动、信息、能量和力如何传递。对受力问题标出力的作用点、方向、约束和力臂；对电路或硬件标出信号、电流或数据的路径。区分实际流动与仅用于分析的箭头。
4. **工作原理**：沿上述路径解释因果关系，比较正常工作与改变一个部件或输入后的行为。说明关键假设和适用范围。
5. **数学模型**：在直观过程明确后给出必要的公式，逐项对应图中的部件或物理量，写明单位、方向约定、边界条件和近似。用一个小算例检查量级及结果的物理意义。
6. **实际应用与失效**：指出真实设备中的用途、常见损耗或限制，以及典型失效如何从结构和流程中产生；区分简化模型与真实设备。

这是默认顺序，不要求每次覆盖所有环节。用户只问识别部件时可停在结构图；用户直接要求计算时，先用最小示意明确模型与假设，再计算。

## 可视化选择与检查

- 优先使用现成且可信的用户图片、图纸或设备视图；需要引用特定实物或规格时核对可靠来源。不可确认的结构要标为示意。
- 按问题选图：空间关系用结构图或截面图，力与转动用受力图，随时间变化用多帧或动画，信号与能量用流向图，参数变化可用交互图。可用的可视化或图像能力能明显提升理解时，尽量调用并展示；简单问题用清晰的内联图即可。
- 图中只保留解释所需信息；标注尺度、方向和箭头含义，避免错误比例、凭空添加部件或把力、能量、信号混为一条流。
- 给一个预测题，例如“拿掉阻尼器后会怎样”，再用模型或现象验证，检查学习者是否能从图推到行为。

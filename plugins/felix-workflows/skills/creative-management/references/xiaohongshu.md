# 小红书作品

用于小红书图文或视频的选题、内容组织、素材、封面、版本、发布准备及复盘。先确认受众、表达目标、图文或视频形式、用户现有素材与采用风格。

- 选题与内容：组织标题、开篇、核心信息和必要补充；个人体验、资料事实和研究判断分别表达，不把未经核实的信息写成亲身经历
- 图文或视频制作：图文按阅读顺序安排图片与文字，视频按脚本与素材制作；保持封面、内页、正文和配音一致，检查缩略预览与正文中的可读性
- 版本与平台适配：保留原稿、采用封面、素材和成品，按当前要求核对媒体规格、标题与正文限制；不把其他平台的文案或成片直接视为已完成适配
- 发布准备：整理标题、正文、封面、媒体和相关标签，核对具体作品与账户。草稿完成、上传准备和已发布分别记录
- 作品管理与复盘：沿用作品标识、采用版本、实际发布时间和链接；依据真实曝光、阅读、互动及反馈分析，注明期间与口径，不虚构平台数据

从学科或行业笔记改编时，保留事实条件、适用边界和作者观点，按本次作品目标选择表达；管理作品不自动更改源笔记或其他平台上的内容。

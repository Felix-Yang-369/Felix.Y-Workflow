# 公司 Logo 横图规范

## 版式

- 成品固定 **16:9**，推荐 1920 × 1080 像素或同等清晰度。若素材不是 16:9，应在制作阶段适配画布，不拉伸标识。
- 背景使用该品牌核实过的主色，通常为干净的纯色。选择官方提供、与背景形成清晰对比的彩色、黑色或反白标识版本；不随意改色。
- 标识作为一个整体在画布中央，四周留白；图标加文字时从左到右排列。品牌正式字标本身的字距、比例和细节应保持原样。中英文组合可按官方版式在右侧上下排列。
- **以 Gallery 卡片中的辨识度确定视觉尺度**。先识别素材中实际可见图形与文字的边界，去掉多余透明或纯色外边距，保留官方要求的净空；占比按可见标识计算，不按原文件尺寸计算。
- 常见横向字标或左图右字组合，首稿可见宽度约占画布 **65%–80%**，两侧通常各留 **10%–17.5%**；高度随官方比例自然决定。较高的徽记或上下组合，可见宽度通常约 **50%–65%**，或高度约 **35%–50%**，按卡片中的公司名清晰度与视觉重量判断。已有用户认可的同库样本时，以样本为准，不机械套用百分比。
- 不设跨品牌统一的 Logo 高度上限，不再用“1920×1080 成品内最多高260像素”等固定值压小所有标识。先用官方横版兼顾横幅；不得自行把官方上下组合拆成左右组合，也不得为凑尺寸拉伸标识。
- 不加口号、行业标签、装饰、渐变、阴影、水印或其他公司的标识，除非它们属于官方选定版本或用户明确要求。
- 必须看约 **270×150 像素**的实际卡片或同等缩略图：公司名应一眼可辨，标识不应成为大片留白中的小点。另查页面横幅的裁切与位置，记录两处结果，不以大图看着清晰代替卡片验收。

## 三张代表案例的读法

用户提供的 Meta、美团、Ctrip 图片用于说明**品牌色背景、居中标识、左图右字**的视觉方向。Meta 是白色图形与英文名横排；美团是黑色图形与中文名横排；Ctrip 是白色图形在左、英文与中文组合在右。案例本身画幅不完全相同，新的交付物统一按 16:9 制作。具体公司应核对自己的当前官方素材，不机械套用这三家的颜色或标识。

## 素材与生成判断

1. 优先找官网品牌中心、媒体库或官网实际使用的图片；网络搜索用于发现来源和候选，不直接采用无来源的转载图。
2. 检查现成图的品牌版本、清晰度、背景色、构图、比例与使用条件。全部满足则直接上传，避免无必要的再生成。
3. 若现成图不满足画幅或背景要求，以核实过的官方 Logo 和品牌色作为 Image Gen 参考；要求其只制作展示排版，保持图形和文字准确。生成后必须与官方素材逐项比对，尤其是中文、英文和图标细节。
4. 若 Image Gen 反复写错品牌文字或改变图形，不交付近似品。继续寻找可用官方成图，或报告缺少可靠素材的具体原因。

生成提示词可按目标品牌调整：

> 制作一张 16:9 的公司 Logo 展示图。背景使用已核实的品牌主色 [颜色]。将提供的官方 [品牌] 标识视作一个完整图像元素，保持其字距、比例、图形和内部排列，不重新设计或重新拼写。所选官方组合实际包含的文字为 [逐字列出]，禁止补写公司全称、翻译、副标题或口号；注册标记按参考保留。整组居中，按实际可见标识边界计算，横向组合起稿宽度约为画布的 [结合形态选择65%–80%；较高组合另按视觉重量确定]，高度随原比例决定，不套统一高度上限。保留必要净空，在约270×150像素的卡片中公司名仍一眼可辨。仅包含选定的官方标识，不添加其他元素。输出清晰的横向图片。

## 改版与验收

1. 先检查标识内容，再检查实际显示。准确性包括：没有错字、漏字、额外英文名或翻译；没有混入旧版本；图形和字标与选定参考一致。生成提示词也必须通过这一检查，不能把提示词自行添加的内容误当作官方要求。
2. 仅以下情况需要后续版本：标识内容存在明确错误；画幅或清晰度不满足交付；在目标页面的实际预览中重要图形或文字被裁掉；用户要求改版。单纯觉得“还能更小、更整齐”或未验证的裁切猜测不构成理由。
3. 裁切问题先在目标页面验证，不从截图上可见的视觉放大直接推断原图尺寸错误。先用官方横版、封面位置及正确的 Page cover 预览兼顾两处。上下组合等形态若仍无法同时“大卡片且完整横幅”，按用户偏好处理；默认保留卡片可辨的尺度，并如实说明横幅裁切，不继续缩小到难读，也不擅自更改数据库视图配置。
4. 确需改尺寸时，保留标识及其内部比例，一次调整到有依据的目标尺度，并检查封面与 Gallery。避免连续按 55%、50%、140% 试探生成；缩放不是让 Image Gen 重画商标的理由。只有用户明确要求其他编辑方式时，才改用其他图像编辑工具。
5. 分别验收两种显示：Gallery 卡片中完整、公司名可辨、视觉尺度与同库样本相称；页面横幅中文字和图形的实际裁切情况明确。优先做到两处完整；存在已确认的形态冲突时，记录取舍，不把一处通过写成两处均通过。合格即停止；用户已选定的版本遵从其选择，不做未经要求的微调。
6. 每个候选独立保存并标记原因。上传选定版本后等待上传完成，确认封面文件已经改变，再离开页面；批量上传逐页完成验收。复核属性、正文和图标未改，区分 API 回读与浏览器目视检查。

## 官方来源示例

- [美团媒体资源](https://www.meituan.com/media)：提供美团及业务标识的下载入口；逐个区分主品牌与业务品牌，并留意页面所列使用条件。
- [Meta 品牌资源](https://about.meta.com/brand/resources/meta/company-brand/)：官方品牌入口，可能需要登录；不能因页面暂不可读就推断某张转载图是最新官方版本。
- [Trip.com Group 品牌列表](https://group.trip.com/brands)：Ctrip 与 Trip.com 分列，研究页面要先确定对应的是哪个品牌。

# 知识管理

先读[公共执行规则](../../references/execution-rules.md)，再按任务读取下表的完整原模块。独立模块是可编辑的规则原件，入口仅负责选择；不得以本页概述替代模块中的详细规则。

| 当前任务 | 必须读取 |
|---|---|
| 学科数据库视图、属性、布局或管理规范本身 | [学科数据库规范](references/notion-academic-database-manager/workflow.md) |
| 学科正文、章节、知识归属、公式、列表或双栏 | [学科笔记规范](references/notion-note-steward/workflow.md)及其要求的共同执行、格式和教材参考文件 |
| 正文配图、实物展示、标注或概念图 | [学科插图](references/academic-illustration/workflow.md)，并读取目标正文的相关规范 |

执行前确认真实对象、页面身份、路径和当前授权范围。“方案”提供可审阅的只读方案；随后明确执行时承接同一对象和已确认要求。保留用户在当前任务中保存的模块修改，不从旧缓存恢复规则。修改 Skill 文本本身不授权修改 Notion。

学科数据库模块中当前保留了用户最新手动编辑，也保留了原有未同步段落；读取[原文差异说明](../../references/migration-notes.md)。只迁移或编辑规范时保持原文；实际配置遇到会改变结果的矛盾时，仅澄清受影响项并继续不受影响的工作。

涉及公司或行业正文，转读[研究管理](../research-management/SKILL.md)；涉及封面和 Logo，转读[创作管理](../creative-management/SKILL.md)；用户要求教学时转读[学习管理](../learning-management/SKILL.md)。结构、内容、原有资源和视觉显示分别验收。

旧工作流名称和新文件位置见[迁移索引](../../references/skill-map.md)。原模块中的历史维护路径和旧调用名以该索引对应的现址为准。

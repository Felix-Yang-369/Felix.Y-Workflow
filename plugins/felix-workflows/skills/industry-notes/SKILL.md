# 行业笔记

本入口在 FELIX WORKFLOW 的一级导航中排第二，统一承接行业和公司笔记及其视觉素材。先读[公共执行规则](../../references/execution-rules.md)，按当前对象读取下表的完整模块。

| 当前任务 | 必须读取的完整模块 |
|---|---|
| 行业或细分行业分类、层级、正文与比较资料 | [行业笔记](references/notion-industry-steward/workflow.md)及其架构、字段参考文件 |
| 公司正文、现有属性、集团或母子公司关系 | [公司笔记](references/notion-company-steward/workflow.md)及其公司指南与企业字段规范 |
| 行业、细分行业或企业库的系列封面 | [行业封面](references/notion-cover-designer/workflow.md)及其样式参考 |
| 公司官方标识展示、页面图标或明确要求的原创 Logo | [公司 Logo](references/company-logo/workflow.md)及其图像规范 |

分析或优化笔记时，继续读取原模块要求的[完整覆盖与完成标准](../academic-notes/references/notion-note-steward/references/completion-workflow.md)。通用格式按实际引用读取；共用格式不代表把行业、公司套成学科知识树。

保留行业研究深度与公司简短概览的原有分工。正文和现有属性优化不扩展为合并公司、迁移页面、重命名属性或更换封面；只做封面或 Logo 时也不顺带改正文和数据库。企业字段规范以最新已保存原件为准。

研究当前数字、状态、领导人或监管进展时核实当前权威来源，注明地区、期间、主体与口径。只读方案保持只读，明确执行承接已确认方案；覆盖、返工诊断、资源保留和分别验收的要求继续适用。

视觉任务保留官方品牌依据、已选版本、提示词、画幅、裁切与系列一致性要求。区分生成、上传与实际应用；应用前核对目标，保存后分别检查资源回读、卡片和页面横幅显示。

学科内容、学科插图和学科封面归[学科笔记](../academic-notes/SKILL.md)。把行业或公司研究改编为个人博客、抖音或小红书作品时，使用[创作管理](../creative-management/SKILL.md)完成平台表达；源笔记维护和公开发布分别按任务授权处理。

本入口承接原研究管理的行业与公司职能。旧名与模块现址见[完整索引](../../references/skill-map.md)；论文评审、自动科研实验等流程仍不由这一架构调整自动引入。

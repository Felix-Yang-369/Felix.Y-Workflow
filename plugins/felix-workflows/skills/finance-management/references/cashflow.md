# 收支、预算与对账

这是一份新增的方法文件，不包含真实账户记录。先确认用户提供的数据和当次授权，使用实际可得的文件或连接。

## 确认口径

确认账户范围、期间、记账日期与入账日期、币种、金额正负约定及用户需要的产物。只读检查不写回原始流水；需要保存整理结果时采用新文件并保留原件。字段缺失保持未知，真实 0 与空白分开。

## 整理与核对

1. 保留原始记录与来源，识别行粒度和提供方交易 ID。重叠期间按可靠 ID 去重；没有 ID 时用账户、日期、金额、币种和摘要辅助匹配，将不确定重复留待复核
2. 区分消费、收入、退款、费用、利息、现金提取和账户间转移。自有账户间转账、信用卡还款及资产买卖不能在不同记录中重复算作消费或收入；对应关系不明时标为待核对
3. 沿用用户已有分类，分类改动保留原始摘要与调整依据。预算按用户给定的分类、期间和目标计算，不擅自替用户设定财务目标
4. 按每个账户和币种分别核对期初余额、期间流入流出及期末余额，考虑未入账、退款和跨期项目。缺少余额时只能检查交易汇总，不能宣称完成余额对账
5. 跨币种汇总需要明确汇率、时点与来源，保留原币金额；没有一致换算依据时分币种列示

## 输出与验收

给出实际覆盖期间、账户范围、收支分类、对账差异和未分类／待匹配项。记录导入条数、重复处理与缺失情况，对汇总复算并回读保存结果。不以看似平衡的总数掩盖未核对差异，不上传或对外发送流水。

# 投资复盘与交易档案

这是一份新增的方法文件，继承现有本地归档实践中的可复用方法，不打包真实持仓、账号或交易快照。优先读取用户指定档案的 README、更新工作流和验证脚本，保留其已经采用的数据契约。

## 真实数据与增量归档

1. 确认目录、连接、账户范围、币种和实际抓取时间。当前连接未暴露的账户信息不猜测，也不据此声称覆盖全部关联账户；范围发生变化时分档处理
2. 获取接口真实数据后立即保存完整响应、查询期间、请求与捕获 UTC 时间，使用新文件名保留历史。失败响应也保留，但不作为零笔成交或成功输入
3. IBKR 成交查询如仍支持预设期间，常规顺序读取 DAYS_90 和 YEAR_TO_DATE；跨年、中断或定期核对再按档案规则顺序补查可用季度。使用工具当前 schema，不承诺任意起止日期、分页或全部历史覆盖
4. 使用档案已有合并器按可靠交易 ID 增量合并，保留更正与备份，重建对应年度文件。运行独立核验并回读清单，检查唯一 ID、年度并集、条数与哈希；本地脚本不等于已获取新数据
5. 查询部分成功时，只合并核验通过的成功数据并标注缺口。重试有界，保留错误与未知字段，不重置档案或改脚本掩盖异常

## 持仓、收益与市场解释

- 区分收盘价格、盘后价格和抓取时账户估值，迟到抓取不冒充此前收盘快照
- 净值变化与投资收益分开，流入流出不能当作收益；按真实返回注明 TWR 或 MWR，百分比与小数口径核对后再展示
- 持仓、现金、收益和配置按匹配的账户范围、日期、币种与分母比较。无法精确对账的差异保留并说明，不强行归零
- 需要市场事实时先核对真实交易日和已收盘状态，再按真实持仓研究相关宏观、行业和公司信息，优先权威原始来源并记录时间

## 输出与范围

分别报告归档状态、数据时点、收益分析和核对缺口；报告新增、更正、总条数、实际覆盖期间及未核实历史。已有日报的重复检查和运行状态继续沿用档案规范；本技能不会自动创建、停止或迁移定时任务，也不自动下单、转账、升级付费数据或发送私有档案。

# 行业封面风格指南

本文件集中维护画幅、裁切安全区、基础视觉风格和主题差异。默认不加文字；用户明确要求的例外按主说明执行。

## 画幅与裁切安全区

- 默认使用 **16:9** 横向图片，用户指定其他比例时按要求执行。
- 主要主体及可辨认的轮廓保持在画布**中央 60%** 的范围内。
- 背景纹理和环境细节延伸至各边缘，使不同尺寸的裁切仍然自然。
- 避免小字、细小标签、过紧的边框，以及贴边的重要细节。

## 图片来源与已有封面

- 已有封面且用户没有要求更换或重新生成时跳过，不额外生成图片。
- 在封面任务范围内，为确认没有封面的页面补图：可以简单搜几张候选图并选用，也可以参考这些图生成，或直接生成；按主题选择即可。
- 优先协调已有同级封面的风格；下方技术插画设定用于适合这种视觉的生成任务，不要求所有搜到的图片都转成技术插画。
- 新图片默认 16:9，注意 Notion 页面横幅和画廊可能采用不同显示裁切。

## 适合科技与工业分支的技术插画参考

| 项目 | 默认要求 |
|---|---|
| 风格 | 精致的电影感技术插画，适度的三维纵深，清晰的图解结构 |
| 背景 | 深海军蓝至近黑色，辅以轻微网格或空间氛围 |
| 灯光 | 共用青色与蓝绿色轮廓光，控制发光强度 |
| 材质 | 根据主题使用玻璃、拉丝金属、发光数据路径、半透明面板或细小粒子 |
| 构图 | 一个明确的中央系统或符号，辅助细节沿水平方向展开 |
| 完成度 | 清晰、精致、有学术感，可作为正式成品；避免活泼的剪贴画风格 |
| 文字 | 默认不嵌入文字、标签、Logo、签名或水印 |

## 示例：科技行业内的视觉区分

| 主题 | 核心视觉元素 | 强调色 |
|---|---|---|
| 半导体 | 晶圆、光刻或芯片制造场景，按页面实际细分方向选择 | 冷青色 |
| 软件 | 真实的软件工作场景或信息流，不使用虚构界面截图 | 蓝色 |
| 医疗 | 与具体细分行业相符的设备、药品研发或服务场景 | 青绿色 |
| 消费品 | 可辨认的产品与使用场景，不模仿特定品牌包装 | 暖琥珀色 |

## 可复用的生成提示词

替换“具体主题概念”，沿用同系列的其余视觉设定。`stylized-concept` 是用途标识，保持英文。

```text
用途：stylized-concept
资源类型：行业知识页面封面横幅
主要需求：<具体行业及其代表性产品、服务或流程>
场景与背景：<与该行业相符的真实场景或抽象环境>
风格与媒介：<参照现有同级页面选择摄影、写实插画或图解风格>
构图与画幅：16:9 横向图片；中央主体位于中间 60% 区域；边缘只放可裁切的环境细节；居中裁切后仍可辨认
灯光与氛围：与同级系列协调，使用一种行业主题强调色，保持主体清晰
限制：无文字、无标签、无 Logo、无商标、无水印；无人物；不使用界面截图；与同级封面风格一致
避免：杂乱、过量霓虹光、细小符号、靠近边缘的重要细节
```

# 创作管理

先读[公共执行规则](../../references/execution-rules.md)，按素材用途读取完整原模块，不把不同封面样式混作同一模板。

| 当前任务 | 读取的完整模块 |
|---|---|
| 学科图解封面、学科系列海报 | [学科封面](references/secondary-discipline-cover/workflow.md) |
| 写实摄影、真实场景与材质的学科封面 | [写实学科封面](references/photorealistic-discipline-cover/workflow.md) |
| 行业与细分行业封面 | [行业封面](references/notion-cover-designer/workflow.md) |
| 官方公司标识展示、页面图标或明确要求的原创品牌设计 | [公司 Logo](references/company-logo/workflow.md) |
| 配合具体知识点的正文插图 | [知识管理](../knowledge-management/SKILL.md)中的[学科插图模块](../knowledge-management/references/academic-illustration/workflow.md) |

原有参考图片、模板、标题、画幅、版本选择、官方标识和裁切规则全部保留。用户已选定的版本按其选择执行，局部修改保持其他已认可内容。

区分构想、提示词、生成素材、上传及实际应用。应用到页面前核对准确目标；保存后分别检查资源回读、Gallery 卡片和页面横幅的实际显示。生成或导出图片不等于已经应用到页面，静态预览不等于宿主视觉验收。

制作公司或行业素材时，需要的对象事实与品牌依据由对应原模块及[研究管理](../research-management/SKILL.md)核实。不得因为本次入口整合而批量更换历史封面或数据库配置。

# Felix 工作流偏好

用户可以直接编辑本文件和各领域的独立 Markdown；其内容需由相关入口明确读取才用于当前任务。用户在对话中的最新明确要求优先。

- Plugin 统一名称、版本、图标和分发；六个入口按任务选择完整参考模块
- 保留当前语言与领域术语，学科、行业、公司和素材的双语命名及格式按相应原模块执行
- 先提供方案的请求保持只读；明确执行时承接方案与已确认要求，局部纠正不清空先前的有效要求
- 真实来源、完整知识内容、可计算例子、适用边界和分项验收按原模块处理
- 学习讲解保留当前主线与卡点；局部追问直接处理，练习节奏按用户要求
- 学习进度、账户、日历和资源等具体数据以当前指令及相应模块为准，不能根据正文修改自行推断
- 只使用免费、已有订阅或现有授权资源；不新增费用
- 不在插件包中保存凭据、完整账户信息、真实金融快照或业务数据库

本文件是公共偏好的轻量入口，具体业务规则保留在完整原模块中，避免以通用概述覆盖用户已编辑的细节。
